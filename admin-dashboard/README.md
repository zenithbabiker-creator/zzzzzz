# Product 3: AgriTrack Administrative Web Dashboard (Phase 4)

Independent React web application for agricultural operations management.

## Scheduled Responsibilities (Phase 4)
- Administrator login and RBAC session management.
- Employee and device management console via Product 2 (`central-backend`) APIs.
- Interactive OpenStreetMap geographical live & historical route visualization.
- Date-range route playback, offline device monitoring, and CSV/Excel report exports.

## Strict Boundaries
- **No** GPS coordinate collection or Room/IndexedDB offline sync engine.
- Communicates exclusively with Product 2 (`central-backend`) over authenticated HTTPS APIs.
